Project pipeline and what is real in this prototype

  1. Demo ✓layout, controls, Cp field, Cl checks
  2. Verifycode review, 3 known issues
  3. TrainNNfoil on CPU (small meshes)
  4. ValidatePINN vs FVM error tables
  • Real now: airfoil geometry, panel solver, Cp field and curve, Cl from pressure, thin-airfoil check, Mach correction, reference-file overlay with RMS error, timing.
  • Stand-in: the solver itself (PINN replaces it). Mach uses the Prandtl–Glauert rule, an approximation of the compressible Euler flow NNfoil solves.
  • Not built yet: PINN backend, training history, shape list from trained models, UIUC shapes.
Scope: inviscid, subsonic flow. A fast screening tool that complements, not replaces, high-fidelity CFD.
