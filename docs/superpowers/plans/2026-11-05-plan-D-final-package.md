# Plan D: Final Package (Docs, Report, Slides, Offline Test, v1.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. This is a **guide**: you write the code.
> The roadmap (`2026-11-05-aeronet-v2-roadmap.md`) wins on any conflict.

**Goal:** deliver P17–P22 from the roadmap: READMEs, report, slides, synopsis, progress report, papers
guide and viva sheet, all with **numbers pulled from `results/summary.csv` by script**; then an offline
clean-copy test and the `v1.0` tag.

**Architecture:** the text is written as Markdown in `docs/deliverables_src/`. Numbers appear as
placeholders (`{{E2|pinn|50x25|rms_cp}}`), which a script fills from `summary.csv`. A missing number is a
**hard error**, never a blank. Small builders turn the Markdown into `.docx` (python-docx) and `.pptx`
(python-pptx). Output goes to `deliverables/` and PDFs to `deliverables/pdf/`.

**Tech stack:** python-docx 1.2, python-pptx 1.0.2 (both checked on this machine), Markdown, git.

**Prerequisite:** Plan C is complete (all `summary.csv` rows, `results/figures/*.png`, `results/tables.md`
and the screenshots in `docs/milestones/img/`).

## File map

| Path | Responsibility |
|---|---|
| `research/docs_build/numbers_fill.py` | `load_rows(csv)`, `lookup(rows, exp, method, mesh, column, case=None)`, `fmt(value, column)`, `fill(text, rows)` |
| `research/docs_build/build_docx.py` | `build(md_text, out_path, base_dir, font="Times New Roman", size=12)` |
| `research/docs_build/build_pptx.py` | `build(md_text, out_path, base_dir)` |
| `research/docs_build/build_all.py` | CLI that fills and builds every deliverable; `--check` only fills, to find missing numbers |
| `research/tests/test_docs_build.py` | unit tests for the three modules |
| `docs/deliverables_src/{report,slides,synopsis,progress,papers_guide,viva}.md` | the source text |
| `deliverables/*.docx`, `deliverables/3_Panel_Presentation.pptx`, `deliverables/pdf/` | the output (committed) |
| `README.md`, `app/README.md`, `docs/verification.md`, `docs/demo_script.md` | updated docs |

**Placeholder syntax:** `{{experiment|method|mesh|column}}` or `{{experiment|method|mesh|column|case}}`.
`lookup` must match **exactly one** row, otherwise it raises a KeyError naming the placeholder.
Formatting: rms, max and cd use 4 decimals; cl and cl_ref use 3; train_s shows "N s" below 120 and "N.N
min" otherwise; infer_ms shows "N.NN ms". Read every `.md` with `encoding="utf8"`, because the text
contains `×` and `°`.
